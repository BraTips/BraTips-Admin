# BraTips public product design

## Experience
- Dark navy + BraTips pink visual system from the existing admin logo.
- Public-first navigation: users can browse picks, tipsters, Bet of the Day and the track record without logging in.
- Authentication gate only appears when a user tries to play/add a pick or access account tools.
- Mobile responsive cards and tables.

## Core journeys
1. Visitor → Home → Latest Picks → Play Pick → Login/Sign up → My Picks.
2. Visitor → Tipsters → Tipster Profile → review historical record → Play Pick.
3. Visitor → Become a Tipster → application → admin approval → tipster dashboard.
4. User → My Picks → track stake, odds and potential return.
5. Tipster → Dashboard → submit prediction → admin review → publication → settlement.

## Boundary
The included My Picks flow is a tracking interface. It does not collect deposits, execute wagers at bookmakers, or process real-money payments. A real-money sportsbook layer would require a wallet/payment provider, wagering ledger, compliance controls and bookmaker/odds execution integration.
